Make a filter sweep

Open a low-pass filter over four bars so a synth moves from dark to bright as the next section approaches.

  1. Route a sustained synth to its own Mixer insert. Add Filter and select LP. Sweep Cutoff while the part plays so you know which values sound dark and open.
  2. In the Playlist, drag on the ruler to select the bars you want to sweep over. Right-click the Filter’s Cutoff knob and choose Automate on the playlist. The new clip covers the selected loop. With no loop, it starts from the start marker and lasts four bars.
  3. Drag the clip’s left endpoint down and its right endpoint up. Drag the bottom edge of the track header down if you need more room to see the line. Play in SONG mode from the start of the clip. The Cutoff knob follows the rising line and the highs come back as the section plays.

Edit the shape

To keep the synth dark longer, drag the small dot between the endpoints to bend the ramp, or right-click empty space below the clip header to add a point. Put that point late in the clip and close in height to the first point. The horizontal position is when the value changes. The vertical position controls how far the filter opens. Play again and listen for the change to happen nearer the transition.

Choose Hold on the point where a value should jump. For example, add a high point on a section boundary, right-click it and choose Hold. Cutoff stays at the preceding point’s value until it reaches the high point.

If the envelope stops driving the knob after you move it by hand during playback, right-click it and choose Re-enable automation. If the clip is hard to find, choose Select automation clips from the same menu.

Record a control move

  1. Right-click the transport’s Record button. Enable Automation in the record filter and disable audio and notes if you only want to capture the control move. Leave Latch off for touch recording, which writes until you release the control. Enable Latch to keep writing its last value until you stop.
  2. Set the playhead just before the move. Arm record, start playback in SONG, and sweep Cutoff through the transition. Stop playback and turn recording off.
  3. Look for the recorded points in the automation clip. Replay the same bars with hands off the knob. If a movement is too abrupt, drag its points or bend the section between them.
