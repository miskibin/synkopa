Analyze and extract from audio

Find a tempo and key by ear and on the grid

  1. Open a Playlist audio clip’s menu and choose Detect tempo, key and chords…. For a project-wide estimate from active audio, use the BPM menu’s Detect tempo and key from the project….
  2. Compare the leading BPM with the half- or double-time alternatives. Count where the beat should land. If it stays aligned through several bars, choose Set tempo. From the clip dialog this changes the project tempo and adjusts that clip’s length so the same source region plays.
  3. Check the key candidates against a sustained bass note or chord. A short or quiet clip can yield no tempo, and percussion alone may give no useful key. Analyze a longer, clearer passage or leave the existing settings when the result disagrees with what you hear. If you use Pitch Correct, the dialog can send the chosen key and scale to that effect.

Turn detected chords into a pattern

  1. In the same dialog, install the optional ChordMini model if prompted. Tempo and key estimates appear separately.
  2. Choose Detailed for more detailed chord names or Simple for a reduced reading. Click a chord or drag across the timeline to choose a range. Use Whole clip to restore the full range.
  3. Choose the destination instrument, then Send to piano roll. Compare the generated notes with the recording and fix chord changes, voicings or octave choices before arranging the pattern.

Convert a sung melody to MIDI notes

  1. Use a clip with one clear melodic line. Open its menu and choose Convert to MIDI…. For a mixed recording, try extracting the vocal stem first.
  2. Preview the notes. Raise Shortest to omit short consonants or breaths, and narrow the Lowest and Highest notes to remove obvious octave errors. Use As sung to retain timing or select a grid to snap the notes.
  3. Choose a new piano or an existing channel and click Convert. Synkopa creates a pattern below the audio clip and opens it in the Piano roll. Compare the two, then fix starts, durations or missed notes.

The built-in tracker can convert a melody without the optional GAME note finder. If notes repeat on the same pitch or end in the wrong place, see Better notes… in the dialog for the Pitch editor’s model download. If the preview is empty, widen the range, lower the minimum duration or choose another region.

Separate the parts of a mixed recording

  1. Save the project before separating. Open the audio clip’s menu and choose Extract stems…. Select the parts you need: Drums, Bass, Other and Vocals.
  2. The first run downloads HTDemucs. Click Download and extract, or Extract once it is installed. You can close the dialog with Run in background and return through the status chip. Avoid editing the source region until it finishes.
  3. The separated clips land on new tracks below the original, aligned to its start. Synkopa mutes the original. Solo each result and check alignment, bleed and artifacts before you use it. Undo removes the whole set in one step.

Extraction uses the clip’s region. Stretch, pitch, fades and gain carry over, while detailed Pitch editor edits do not. If you need the audio after effects, render it in place first. For a clip over 30 minutes, split it and process the required sections.

Recover from a model download or analysis failure

  • If the first model download fails offline, reconnect and choose Try again in the dialog. Once the relevant model is installed, processing runs locally. Chords, stems and the optional neural note finder have separate installation steps.
  • If the audio file is missing, relink it before processing. If you edited or deleted the clip while separation was running, restore the region and start again.
  • If a result sounds wrong, keep the original, audition alternatives or shorter regions, and edit the generated pattern or audio on the Playlist. A tempo/key estimate or detected note is a starting point for listening.

Continue with clip editing, mixing and routing, or exporting the finished arrangement. To export your own mixer tracks as files, use the Export dialog’s Stems mode.
