If letter keys play notes, turn off View → Computer keyboard as piano. If your system uses the function keys, use the View menu.

The project plays in silence

  • Check PAT/SONG. PAT plays notes in the current pattern. SONG plays clips in the Playlist from the start marker.
  • Check for a muted channel, Playlist track, or mixer insert, and clear any solo you left active.
  • Open File → Settings… → Audio. Check that the driver is running and Output is set to the device you are listening through. On Windows, select WASAPI if your ASIO interface is disconnected.
  • If playback crackles, try a larger Buffer. If you use JACK or PipeWire JACK, change the buffer in that audio server.

The input meter does not move

Check the device and channel in Audio settings. To open the input, arm Record with Audio enabled or turn on Monitor input. If the meter moves, check the recording steps.
