In the docs, Ctrl or ⌘ + K searches guides. In the app, Ctrl + K runs commands.

If letter keys play notes, turn off View → Computer keyboard as piano. If your system uses the function keys, use the View menu.

The project plays in silence

  1. Open the demo with File → Open demo project. Press Space. If nothing plays, confirm the audio output and driver. On Windows, switch to WASAPI if your ASIO device is unplugged.
  2. If the demo plays, reopen your project. Choose PAT to hear the selected pattern or SONG to hear Playlist clips from the start marker. Set the start before the material you want to hear.
  3. Follow the signal. Check that the channel or track is unmuted and its insert meter moves. Clear unwanted solos. Then check the Master meter and output level.
  4. If only specific clips are silent or show a missing label, relink their audio. For crackles, check underruns and adjust the buffer.

The input meter does not move

  1. Choose your device under Audio → Input. Check the operating system’s microphone permission and that the interface is connected.
  2. Right-click Record, enable Audio, then click Record once to arm it. Speak into the mic and watch the IN meter. Choose the correct Input channel after the device opens.
  3. If IN moves but there’s no new clip, check the track destination and press Space to start. Review the recording workflow before trying another take.

Third-party plugins

Windows and Linux host VST3 instruments and effects. Linux also hosts LV2 effects when liblilv is available. On macOS use the built-in instruments and effects.

  1. Install the plugin in a standard plugin folder for your system. In the Channel Rack, choose + Channel → Plugin instruments (VST3) to load a sound source. For an effect, select the destination insert and use Mixer → Add effect… → Plugins.
  2. If the plugin is missing, choose Rescan plugins in the instrument menu or Rescan in the effect picker. Check the format and any reason shown in the list. Install liblilv if the Linux picker reports it missing.
  3. Open the plugin from its channel or effect slot. If its native window is unavailable, use Synkopa’s parameter list. Play a test note for an instrument, or pass a signal through the selected insert and toggle the effect’s power to check the change.

Save the project to keep the plugin settings. If a project’s plugin fails to load, its slot and settings stay in the project and audio passes through. Restore that plugin on the machine before checking the mix.

If a plugin was loaded when Synkopa last crashed, the startup dialog can Block it from future scans. Recover your project and check whether the problem still occurs without that plugin.

Find a command or ask for help

  1. Press Ctrl + K in the app to open Find a command. Type a command such as Reset window layout, choose it, and press Enter. This runs the corresponding app action.
  2. For help instead of an app command, use Ask ChatGPT or F1. For a specific question, type it in the palette and select Ask ChatGPT in the results. This opens ChatGPT in your browser with your question, the app version if available, and names of visible app views.
  3. If a long question is copied rather than opened with the prompt, paste it in the browser chat. For a reproducible problem, use the support links below.
