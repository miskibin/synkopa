Glossary

The words you meet in Synkopa and in this guide, in plain language.

Automation
A curve on the Playlist that moves a control by itself while the song plays, such as a filter opening over eight bars. See Automate controls.
Bar, beat, step
A bar is one count of “1 2 3 4”; each count is a beat. The Channel Rack splits a bar into 16 steps, four per beat.
BPM
Beats per minute: the tempo of the song, shown in the toolbar.
Buffer
The chunk of sound Synkopa computes ahead of time. Larger means fewer crackles but more delay. See Fix crackles and delay.
Bus
A mixer insert that other inserts send into, so you can treat a group of sounds (all drums, all vocals) with one fader and one set of effects.
Channel
One instrument in the Channel Rack: a sample, a synth or a plugin. See How Synkopa works.
Clip
A block on the Playlist: a pattern, a piece of audio or an automation curve placed in time.
Clipping
Sound louder than the maximum (0 dBFS). It distorts; the toolbar's output meter shows CLIP.
Comp
Short for composite: one performance built from the best parts of several takes. See Record and comp. Not the same as a compressor.
Compressor
An effect that turns loud moments down so a sound stays at a steadier level. See EQ and dynamics.
dB, dBFS
Decibels, the unit of level. 0 dBFS is the loudest a digital file can hold; mix levels are negative numbers below it.
Driver
The software that connects Synkopa to your sound hardware: WASAPI or ASIO on Windows, Core Audio on a Mac, ALSA or JACK on Linux.
EQ
Equalizer: an effect that makes some frequencies (bass, mids, treble) louder or quieter.
Insert
A strip in the Mixer with its own fader, pan and effects. Each channel plays into one insert, and every insert ends in the Master.
Latency
The delay between playing or singing something and hearing it back. A smaller buffer lowers it.
LUFS
A measure of how loud a song sounds over time, used by streaming services. Higher (closer to zero) is louder. See Master and measure.
Master
The last mixer insert. Everything you hear passes through it.
MIDI
Notes as data (which key, when, how hard), not sound. A MIDI keyboard sends them; an instrument channel turns them into sound.
Monitoring
Hearing your microphone or instrument through Synkopa while you play or record.
Pattern
A short piece of music with notes for any of the channels. You place it on the Playlist as clips.
Playlist
The big timeline where clips are arranged into a song.
Plugin
An instrument or effect from another company, in VST3 format (or LV2 effects on Linux).
Quantize
Move notes onto the nearest grid line so they play exactly in time.
Sample
A short recorded sound, such as a kick or a vocal phrase, played by a channel.
Sample rate
How many times per second sound is measured, for example 48000 Hz.
Send
A copy of an insert's sound routed to another insert, such as a shared reverb or a bus.
Sidechain
Letting one sound control an effect on another, such as the kick briefly turning the bass down. See Mix and route.
Stem
One part of a song as its own audio file (drums, bass, vocals). Synkopa can export stems or split a finished song into them.
Take
One recording attempt. Recording over a loop several times keeps every pass as a take, so you can pick the best or comp them.
Transient
The short, sharp start of a sound, such as the click of a kick drum.
True peak
The highest level a file reaches once it is played back, which can be slightly above its highest sample. Measured in dBTP.
Underrun
A moment when the computer could not compute sound in time. You hear a click or crackle.
Velocity
How hard a note is played, which usually sets how loud it is.

The project plays in silence

Work from the outside in: first check that any sound plays at all, then follow the signal through your song.

  1. Choose File → Open demo project and press Space.If the demo is silent too, the problem is your audio device: see Choose where the sound plays.
  2. Open your project again. Check the PAT / SONG switch in the toolbar: PAT plays only the current pattern, SONG plays the Playlist from the start marker.
  3. Check that the channel is not muted in the Channel Rack and that its mixer insert's meter moves.
  4. Look for a lit solo anywhere in the Channel Rack or the Mixer, and turn it off.
  5. Check that the Master meter moves and the main volume in the toolbar is up.

Only some audio clips are silent and say FILE MISSING? Relink their audio. Space does nothing at all? A text box may have the keyboard: click the Playlist and try again.

The input meter does not move

The IN meter in the toolbar shows the level coming from your microphone or instrument. If it stays still, Synkopa is not receiving anything.

  1. In File → Settings… → Audio, choose your device under Input.
  2. Check that the interface is connected and that your operating system allows Synkopa to use the microphone.
  3. Right-click the Record button and make sure Audio is on.
  4. Press R to arm recording, then speak or play.The IN meter moves.
  5. If the sound is on one side or from the wrong socket, set Input channel in Settings to the socket your microphone is plugged into.

“Recording input could not open … Playback works” usually means another program holds the input, or the input and output are devices that cannot run together. Try the same device for both. More in Record and comp.

A plugin does not show up

Synkopa hosts VST3 instruments and effects on Windows and Linux, and LV2 effects on Linux. macOS does not host third-party plugins yet; use the built-in instruments and effects there. CLAP and AU plugins are not supported.

  1. Install the plugin into a standard folder: C:\Program Files\Common Files\VST3 on Windows, or ~/.vst3, /usr/lib/vst3 or /usr/local/lib/vst3 on Linux.
  2. Rescan. For an instrument: in the Channel Rack, + Channel → Plugin instruments (VST3) → Rescan plugins. For an effect: select an insert, click Add effect… (Shift + F9), open Plugins and click Rescan.The plugin appears in the list. If it shows a reason it cannot run, that reason applies to this plugin.

To add a folder outside the standard ones, set the VST3_PATH environment variable. On Linux, “LV2 is unavailable” means the lilv library is missing: install liblilv-0-0 (Debian, Ubuntu), lilv-libs (Fedora) or lilv (Arch) and restart Synkopa.

A plugin says it is not loaded

Synkopa tests each new plugin in a separate process first. If the test crashes, the plugin is not loaded: an effect lets the sound pass through unchanged, an instrument stays silent, and its settings stay in the project. Update the plugin, or choose Load anyway to load it from now on. If Synkopa closed while a plugin was loaded, the next start lists the loaded plugins; Block keeps one out of future scans.

Find a command or ask for help

You do not need to remember where every command lives.

  1. Press Ctrl + K (Help → Find a command).
  2. Type what you want to do, such as export, mixer or reset window layout.Matching commands appear with their shortcuts.
  3. Pick one and press Enter to run it.

Help → User guide opens this documentation in your default browser.

If you type a question rather than a command, the list offers Ask ChatGPT with your question. It opens ChatGPT in your browser with the question, your Synkopa version and the windows you have open, and asks ChatGPT to consult this user guide before answering. F1, the Ask ChatGPT button next to the menus and Help → Ask ChatGPT start a general Synkopa help chat. If the question is long, Synkopa copies it instead: paste it into the chat.

Elsewhere in Synkopa, the status line under the menus explains the control under the mouse and reports what just happened.

  • Open an issue on GitHub for a bug you can repeat. Say what you did, what you expected and what happened.
  • Ask other users on Discord (Help → Join the Discord).
  • See what changed in each version in the changelog, or in the app with Help → What's new.
