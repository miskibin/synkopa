Edit and mix a vocal

Find one off-key syllable in a recorded take, correct it by ear, and check the result against the backing.

Open the recorded phrase Fix one off-key word Compare and keep the edit Tune to a guide performance Route and process the vocal Save and export

Open the recorded phrase

Start with a short vocal clip over your backing. If you followed the recording guide, play your comp and check that the joins sound natural. Save the project with its takes first. Then use File → Save as… and give the working copy a different name. Right-click the comp’s name and choose Flatten comp. The new audio clip is on the same track.

Right-click the resulting audio clip’s name and choose Edit pitch…. Wait for analysis. Pitch editor shows the voiced notes as blobs with the pitch trace over time. It shows breath and other unvoiced sounds below the grid and leaves them unchanged.

If you’re trying the controls without a microphone, drag an existing solo vocal recording into the Playlist. For a quick look at the editor, use File → Open demo project and open Edit pitch… on the first Vox Dark 120 Dm clip on the Dark Vox track at bar 1.

Fix one off-key word

  1. Find it by ear. In Manual, click the ruler just before the word and press Solo to hear the take from that point. Use Play to hear the backing too. Drag a short loop on the ruler to compare the word repeatedly in the mix.
  2. Find the sung note. Compare the blob’s position with the intended note from the melody. Use F to fit the take or Ctrl + mouse wheel to zoom in. If the syllable spans two notes, listen for which note is off and edit that one first.
  3. Move it to the intended pitch. Set the song’s Key and scale. Use the Pitch tool (1) and drag only that blob up or down. The tool snaps to the selected scale. Hold Alt while dragging for a smaller, unsnapped adjustment. Dragging changes pitch while the word stays at its original time.

If the nearest scale note is already the right target, select only the blob and choose Natural, then Correct 1 selected. Strength controls how far the pitch moves. Speed controls how quickly it gets there. Keep Flatten low to retain the singer’s vibrato.

When the pitch move needs more control
  • For a long note that wavers too much, drag Drift (2) up slightly. If a pitch move changes the vowel’s color, try a small Formant (3) adjustment. If one syllable jumps out, pull that note down with Volume (4).
  • When two syllables share one blob, use Split (5) at their boundary before correcting either. Click an existing split to merge it. To reshape a scooped onset or a short slide, draw just that contour with Pencil (6). Alt + drag erases the drawing in that range. Listen after each change.
  • Copy notes copies selected sung notes, or all notes when none are selected. Paste them into the Piano Roll to build a guide melody.
  • If analysis fails, click Try again. The app has built-in detection. Better notes offers the optional GAME note finder, and Download RMVPE in To reference offers an optional pitch detector. The download dialogs show the models’ licenses.

Compare and keep the edit

Play the same loop with the backing. Undo the last pitch move with Ctrl + Z to hear the original, then redo with Ctrl + Shift + Z. Listen to the transition into the word and its ending. If either sounds forced, make a smaller move or use less flattening.

To remove edits from a single note later, select the blob and click Reset notes or press Delete. With the selection cleared, Reset clears the clip’s manual pitch edits. An applied reference stays active until you turn it off. Double-click the ruler when you’re done with the comparison loop.

Tune to a guide performance

When several notes miss the written melody, use To reference in Pitch editor. Add a guide vocal singing the same melody to the Playlist, or place a Piano Roll melody in the Playlist over the target vocal. The guide can sit on its own track so you can mute it for playback.

  1. In Reference, choose the guide recording or the melody channel. Octave → Auto chooses the guide octave closest to your voice.
  2. Check the original, reference, and result curves. Lower Correction to keep more of the original pitch and raise Vibrato to retain its motion. For an audio guide, Ref. Influence blends between the guide’s note centers and the nearest note in the selected key. The take keeps its timing. Sections with an uncertain match are left as sung.
  3. Click Apply and listen. To remove the reference while keeping manual pitch edits, choose Turn off.
Hear the reference pull the melody into tune

Play the guide, then the original and the tuned take. The original is about 47 cents sharp on each note. Listen for all three notes to settle to the guide’s pitches while keeping the take’s rhythm.

Route and process the vocal

  1. In the Playlist track menu, open Mixer channel and choose a dedicated insert. Press F9, select that insert, and play the phrase to confirm that its meter moves.
  2. Start with the insert fader, then use EQ or compression where needed. For an editable one-word repair, keep working in Pitch editor. To tune everything passing through the insert during playback, add Pitch Correct and set its Key and Scale. Bypass the slot to compare.
  3. For a quick processing chain on a separate version, right-click the vocal clip’s name and choose Auto vocal → Auto vocal — singing or Auto vocal — rap. This analyzes the take, can render leveling into a new audio source, and sets up effects such as compression, de-essing and real-time pitch correction on the insert. The rap setting uses harder tuning. If you run it on a comp, it flattens that comp first.

Check the result in the full mix. If the musical pitch edit already works, bypass any extra real-time tuning added to the insert. Keep the pre–Auto Vocal project version if you want to revisit the earlier pitch edits.

Save and export

  1. Save the editable project with Ctrl + S. To share the project with its recordings, use File → Export project as ZIP….
  2. For a listening copy, choose File → Export audio…, set Output to Mix, and pick Song or the Loop around the phrase. Use Tail if you want the reverb to ring out.
  3. To hand the edited vocal off separately, export Stems with the vocal on its dedicated insert. Play the exported file to check the edit and the end of the phrase.
