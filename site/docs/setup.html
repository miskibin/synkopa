Install and set up Synkopa

Install and verify playback Choose your audio driver and devices Fix clicks and recording delay Arrange the workspace Check for an update

Install and verify playback

  1. Download the package for your computer from the latest release.
  2. Windows: run the EXE or MSI. macOS: use the DMG on Apple Silicon with macOS 13.4 or later. Linux: install the DEB or RPM for your distribution, or make the AppImage executable and run it.
  3. Open Synkopa. Choose File → Open demo project and press Space. You should hear the demo and see the Playlist playhead move. If it moves in silence, set your output below.

See the platform notes for macOS first launch and Linux packages.

Choose your audio driver and devices

  1. Open File → Settings… → Audio. Choose a driver. On Windows, start with WASAPI for system audio or ASIO for an interface with its own ASIO driver. On Linux, use ALSA or an already running JACK or PipeWire JACK server. macOS uses Core Audio.
  2. Set Output to the device your speakers or headphones use. Set Input to your recording device. For ASIO, the same driver supplies input and output. Choose Input channel after arming Record or turning on monitoring to open the input.
  3. Set Sample rate to Auto unless the device or session needs a specific rate. Check that Status says running. Play the demo again and check that sound comes through the output you selected.

If you unplug an ASIO interface on Windows, use Switch to WASAPI in the audio notice or select WASAPI in Settings. Switch back to ASIO after reconnecting.

Once playback works, set up a microphone or connect a MIDI keyboard.

Fix clicks and recording delay

  1. Loop a busy part of the song and reset the Underruns counter when a count is present. If it climbs, increase Buffer one step. Play the same part and compare. A larger buffer gives the engine more time but adds monitoring delay.
  2. For recording, start with a stable buffer. To measure where takes land, hold the microphone near a speaker or one headphone cup and choose Measure latency. Synkopa plays a few clicks and sets Recording offset from the measurement.
  3. Record a short test against the click and check where the waveform lands. A positive offset moves recorded audio earlier. If the measurement is uncertain, move the microphone closer and try again.

JACK controls sample rate and buffer size on its server. Change those settings in JACK or PipeWire.

Arrange the workspace

  1. Open Channel Rack (F6), Piano roll (F7), or Mixer (F9). Drag its title bar onto a docking guide, or choose a position in View → Window layout.
  2. For more editing room, double-click the Mixer title bar to maximize it. Use F5 to bring the Playlist forward or restore tucked windows. Use F11 to toggle full screen.
  3. To get back to a known layout, choose View → Window layout → Reset window layout. The Mixer docks below, the Rack and Piano roll float, and the Browser is shown.

Change Theme, interface Scale, or Channel Rack step spacing in Settings… → Look. Set language, note preview, and hints in General.

Check for an update

  1. Open Help → Check for updates, or go to Settings… → Updates to check the installed version and turn Update automatically on or off.
  2. If an update is available, review What's new, then choose Download update when offered. Wait until the app reports the update is ready.
  3. Choose the restart action when you can stop working. Save the project when prompted. After restart, check the version in Updates.

If in-app updating is unavailable for your package, install the appropriate package from the release page.
