Install and check sound

Download Synkopa for Windows, macOS (Apple Silicon), or Linux. See installation notes for your system.

Choose File → Open demo project and press Space. If you hear silence, check your audio output.

Program one bar of drums

  1. Choose File → New project. The Channel Rack opens with Kick, Clap, Hat, and Snare. Press F6 if it is hidden.
  2. Click steps 1, 5, 9, and 13 on Kick, 5 and 13 on Clap, and odd steps on Hat. Right-click to erase a step.
  3. Select PAT and press Space to start or stop the loop.
120 BPM · Tap steps to edit

Add a melody

  1. In the Channel Rack, choose + Channel → Synkopa Instruments — pianos, strings, guitars to add the Grand Piano.
  2. Right-click the piano channel name and choose Piano roll. Click the grid to place notes. Drag a note to move it or drag its right edge to resize it.
  3. Keep the notes within bar 1 and play in PAT to hear the piano with the drums.

Turn the loop into a song

  1. Stop playback and bring the Playlist forward with F5.
  2. In the Browser’s Patterns tab, drag Pattern 1 to bars 1, 2, 3, and 4. Press Alt + F8 if the Browser is hidden.
  3. Click the Playlist ruler at bar 1 to set the start and switch to SONG. Press Space to hear the Playlist.

Edits affect every clip that uses the pattern. To edit just one clip, open its menu and choose Make unique.

Save the project and export audio

  1. Choose File → Save to save the editable .synkopa project.
  2. Choose File → Export audio…. Set Output to Mix, Range to Song, and Format to WAV.
  3. Choose Export…, save the file, and listen to it in your audio player.
