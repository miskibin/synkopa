Make your first song

Install Synkopa, program a beat, add a melody, and export a mix.

Install and check sound

Get the latest release for your system. Use the .exe or .msi on Windows, the .dmg on Apple Silicon Macs, or the .deb, .rpm, or .AppImage on Linux. See the platform notes for startup and driver details.

In Synkopa, choose File → Open demo project and press Space. You should hear OBSIDIAN 2093 and see the playhead move in the Playlist. If it moves in silence, check File → Settings… → Audio → Output, then see playback troubleshooting.

Program one bar of drums

  1. Choose File → New project. The Channel Rack opens with Kick, Clap, Hat, and Snare. Press F6 if it is hidden.
  2. Count from the first square in each row. Click steps 1, 5, 9, and 13 on Kick, steps 5 and 13 on Clap, and every other step on Hat. Right-click an active step to erase it.
  3. Click PAT in the transport and press Space to hear the current pattern loop. Press Space again to stop.

Add a melody

  1. In the Channel Rack, choose + Channel → Synkopa Instruments — pianos, strings, guitars to add the Grand Piano.
  2. Right-click the piano channel name and choose Piano roll. Click within the grid to place notes, drag them up or down to change pitch, and drag the right edge of a note to change its length.
  3. Play the pattern in PAT again to hear the piano against the drums. Keep the notes within the first bar if you want a one-bar loop.

Turn the loop into a song

  1. Stop playback and click the Playlist to bring it forward, or press F5.
  2. Open the Browser with Alt + F8 if it is hidden. In Patterns, drag Pattern 1 onto the first Playlist track at bar 1. Drag it in again at bars 2, 3, and 4 to repeat it.
  3. Click the Playlist ruler at bar 1 to set the start and switch to SONG. Press Space to hear the Playlist.

A pattern stores the notes. Each pattern clip in the Playlist plays an instance of those same notes. To change just one instance, open that clip’s menu and choose Make unique before editing.

Save the project and export audio

  1. Choose File → Save and give the project a name. Open the .synkopa file when you want to keep working on the song.
  2. Choose File → Export audio…. Set Output to Mix, Range to Song, and Format to WAV.
  3. Choose Export…, save the file, and listen to it in your audio player.

Once the first mix plays, try arranging variations or balancing the individual sounds.
