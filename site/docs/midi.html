Set up and record MIDI

Play instruments from a MIDI keyboard or pad controller (or your computer keyboard), record what you play as editable notes, and move note data in and out of Synkopa as .mid files. MIDI is note data, not sound: which keys were played, when, and how hard.

Connect a controller Record notes Import a MIDI file Export MIDI

Connect a MIDI keyboard or pad controller

Playing parts in by hand is faster and more musical than clicking every note. Tell Synkopa which device to listen to and which channel it should play.

  1. Plug in the controller and choose File → Settings… → MIDI.
  2. In Device, pick your controller. Plugged it in after opening Settings? Click Refresh.
  3. Leave Plays on at Selected channel (Channel Rack / piano roll). The keyboard then plays whichever channel you select. Pick one instrument instead if the keyboard should always play that sound.
  4. Leave Velocity at From keyboard so soft and hard playing sound different. Choose Fixed and a value from 1 to 127 if every note should be equally loud.
  5. Select a melodic channel in the Channel Rack and play a key.Settings shows the last note it received, and you hear the instrument.

If it doesn't work

  • No device listed: reconnect it, click Refresh, and check that your operating system sees the device.
  • Notes arrive but nothing sounds: check Plays on, that the channel is not muted, and that the master meter moves.

No controller? Use the computer keyboard

Press Ctrl + T or click Typing piano in the toolbar. The bottom letter row plays from C4 (Z = C4, S = C♯4, X = D4…) and the top row an octave higher, starting at Q. Page Up and Page Down change the octave. While it is on, those letters play notes instead of running their shortcuts, so turn it off when you are done.

Record a performance as editable notes

Recording notes captures what you play into a pattern, so you can fix single notes later in the Piano roll. First tell the Record button to capture notes only.

  1. Right-click the red Record button in the toolbar.
  2. Tick Notes, and untick Audio and Automation.
  3. Leave Quantize notes off for now. (Quantize moves notes onto the grid; you can do it later, only where needed.)

Add to a loop (PAT)

Use this to build up a pattern layer by layer while it loops.

  1. Select the instrument channel and the pattern you want to record into.
  2. Switch the toolbar to PAT. Turn on the metronome if you want a click.
  3. Click Record (or press R), then press Space and play.
  4. Press Space to stop.
  5. Press F7.Your notes are in the current pattern, on the channel you played.

Record against the song (SONG)

Use this to play a part over the whole arrangement. The notes land in a new pattern on the Playlist.

  1. Switch the toolbar to SONG and click the Playlist ruler where the take should start.
  2. Optional: right-click a track header and choose Record into this track to choose where the clip goes.
  3. Optional: turn on 1 BAR for a one-bar count-in.
  4. Click Record, press Space, play, and press Space to stop.A new pattern clip appears on the Playlist. Double-click it to see the notes.

If nothing was recorded

  • Check that Record was lit and Notes was ticked.
  • With a count-in, play only after the count bar.
  • In PAT, look in the current pattern on the channel you played, not on the Playlist.

Unwanted take? Ctrl + Z removes it. To tighten timing afterwards, select just the late notes and press Ctrl + Q in the Piano roll. Recording a microphone or guitar instead? See Record & comp. Turning a sung or played audio melody into notes is Convert to MIDI.

Import a MIDI file

A .mid file from another DAW, a chord pack or a website brings its notes in as an editable pattern, played by Synkopa instruments.

  1. Click the Playlist ruler where the file should start.
  2. Choose File → Import MIDI file… and pick the file. (Or drop the .mid on a Playlist track at the bar you want.)
  3. In the dialog, keep ticked only the parts you want, and check the instrument suggested next to each. Drum parts are mapped to library drum sounds.
  4. Read any warnings at the top, for example about tempo changes the file contains.
  5. Tick the tempo option only if the project should take the file's BPM. Leave it off when the song already has its tempo.
  6. Click Import.A new pattern clip appears on the Playlist and the Piano roll opens on one of its parts.

The tempo changed when it shouldn't have? Undo and import again with the tempo option off. The Playlist uses a 4/4 grid, so the dialog warns about other time signatures.

Import one part into an instrument you already set up

  1. Right-click the channel in the Channel Rack and choose Import MIDI into this channel….
  2. Pick one part of the file.
  3. Tick Replace the channel's notes in this pattern to overwrite, or leave it off to add to them.
  4. Click Import.

Export a pattern or the song as MIDI

Export MIDI to continue a part in another DAW or share an editable melody. A .mid holds notes only: the other app plays them with its own instruments. To share how your song actually sounds, use audio export.

  • One pattern: right-click it in the Browser's PATTERNS tab and choose Export pattern as MIDI….
  • The whole song: choose File → Export song as MIDI…. It writes the pattern clips as placed on the Playlist.

To check the file, import it into a new project. If a pattern's export is greyed out, the pattern has no notes.
