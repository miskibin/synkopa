MIDI setup and recording

Connect a controller Record notes Import a MIDI file Export MIDI

Connect a MIDI keyboard or pad controller

  1. Connect the controller and open File → Settings… → MIDI. In Device, select its port. Use Refresh if you plugged it in after opening Settings.
  2. Set Plays on to Selected channel (Channel Rack / piano roll) to follow your selection, or select a specific instrument to keep the keyboard on that sound. Open the Rack and select a pitched instrument.
  3. Play a short note. Check the connected status and last note in Settings, then check that the intended instrument is audible. Choose From keyboard for performance dynamics or Fixed and a value from 1 to 127 for even notes.

If there is no port, reconnect it and refresh, then make sure the operating system can see the device. If the connection indicator responds but the instrument is silent, check Plays on, channel mute and the master output. With no controller, click Typing piano or press Ctrl+T. Z plays C4 and Q plays C5 at the default octave. Turn Typing piano off to use those keys as normal shortcuts again.

Record a performance as editable notes

  1. Choose the instrument you tested and a pattern. Right-click the red Record button to check Notes. Disable Audio and Automation for a notes-only pass.
  2. For a pattern overdub, select PAT, turn on the metronome if you want a cue. Arm Record, press Space, then play the phrase. Stop with Space. Open F7 on the recorded channel to see notes in the current pattern.
  3. To capture against the whole arrangement, switch to SONG. Click the ruler where you want the take to start. To specify a lane, right-click its track header and choose Record into this track. Enable 1 BAR for a count-in if you want one. Start recording, play a phrase, and stop. Look for a new pattern clip in the Playlist, then double-click it to inspect the notes.
  4. Use Quantize notes in the Record menu if the notes should land on a grid during capture. For a performance with deliberate timing, leave it off, then select only the notes you want to correct and quantize them in the Piano roll.

If no pattern clip appears after stopping, check that Record was armed, Notes was checked, and you played after any count-in. In PAT, check the current pattern and channel instead of looking for a new Playlist clip. Use Ctrl+Z to undo an unwanted take. For microphones or line inputs follow Record audio.

Import a MIDI file

  1. For a full file, set the start position on the Playlist and choose File → Import MIDI file…, or drop a .mid at a position and lane. Select the parts you want and check the suggested instruments. Drum parts map to available drum sounds.
  2. Keep the project BPM for an existing arrangement, or enable the file tempo in the dialog to use its BPM. Review the import warnings about tempo changes or unsupported time signatures, when present.
  3. Click Import. Check the new clip in the Playlist and the opened Piano roll. Switch to SONG to audition it in place. If the arrangement moved tempo unexpectedly, undo and import with the tempo option cleared.
  4. For one part played by an instrument you already configured, right-click that channel in the Rack and choose Import MIDI into this channel…. Choose a single part and decide whether to replace or append to the notes in the current pattern.

Export a pattern or song as MIDI

Right-click a pattern in Browser → Patterns and click Export pattern as MIDI… to share an editable phrase. For the arrangement, place your patterns on the Playlist and choose File → Export song as MIDI…. Give the file a name, then import it into a new project or another DAW to check timing and note parts.

If song export is unavailable, check that the Playlist contains an unmuted pattern clip with notes. A .mid carries musical note data for playback with instruments in the receiving app. For the sound of your mix with its instrument presets and effects, use audio export.
